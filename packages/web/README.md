# `web`

**English** — The game itself: a Vite + React front end with a Three.js engine (`src/web`), a Hono + oRPC API backed by libSQL (Drizzle) and Better Auth (`src/api`), automated tests (`tests`), custom Vite plugins (`vite`) and static assets (`public`).

Useful commands (from the repository root): `bun run dev`, `bun run test`, `bun run build:web`.

**Português** — O jogo em si: front end em Vite + React com engine em Three.js (`src/web`), API em Hono + oRPC com libSQL (Drizzle) e Better Auth (`src/api`), testes automatizados (`tests`), plugins customizados do Vite (`vite`) e arquivos estáticos (`public`).

Comandos úteis (na raiz do repositório): `bun run dev`, `bun run test`, `bun run build:web`.
