# `game`

**English** — Game interface: the shell that runs a match, the in-run HUD, notifications and the overlays (menu, pause, game over, ranking, skins, missions, settings).

**Português** — Interface do jogo: a casca que roda a partida, o HUD durante a corrida, as notificações e as telas sobrepostas (menu, pausa, fim de jogo, ranking, skins, missões, configurações).
